# 🏐 Placar de Vôlei Mobile

Um placar simples, intuitivo e responsivo para contar pontos em partidas de vôlei. Projetado especificamente para uso em dispositivos móveis durante o jogo.

## ✨ Funcionalidades

- **Toque para Pontuar:** Clique na metade da tela correspondente ao time para somar pontos.
- **Correção de Pontos:** Botões dedicados para subtrair pontos em caso de erro.
- **Troca de Lados:** Inverte a posição dos times na tela (ideal para mudanças de quadra).
- **Zerar Set:** Limpa o placar para iniciar uma nova partida.
- **Interface Mobile-First:** Botões grandes e cores vibrantes para fácil visualização sob o sol ou luz forte.
